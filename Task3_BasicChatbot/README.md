# Basic Rule-Based Chatbot

A simple Python-based rule-based chatbot created as part of my CodeAlpha Python Programming Internship.

## Features

- Responds to greetings
- Answers basic questions
- Provides the current time
- Tells a programming joke
- Explains its purpose
- Handles unknown inputs
- Supports exit commands such as `bye`, `exit`, and `quit`

## Technologies Used

- Python
- Functions
- If-elif-else statements
- While loops
- String handling
- Date and time module

## How to Run

Make sure Python is installed on your computer.

Open the terminal in this folder and run:

```bash
python chatbot.py
```

## Example

```text
SIMPLE CHATBOT
Type 'bye' to exit.

You: hello
Bot: Hi! How can I help you today?

You: what is your name
Bot: I'm a simple chatbot built for the CodeAlpha internship.

You: tell me a joke
Bot: Why do programmers prefer dark mode? Because light attracts bugs!

You: bye
Bot: Goodbye! Have a great day!
```
