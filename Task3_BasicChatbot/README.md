# Basic Rule-Based Chatbot

A simple console-based chatbot developed using Python for the CodeAlpha internship.

## Features

- Responds to greetings
- Answers basic questions
- Tells the current time
- Provides a simple joke
- Explains its purpose
- Handles unknown questions
- Allows the user to exit the conversation

## Technologies Used

- Python
- Conditional statements (`if-elif-else`)
- Functions
- While loop
- String handling
- Date and time module

## How to Run

1. Make sure Python is installed.
2. Open the terminal in this folder.
3. Run:

```text
python chatbot.py

EXAMPLE

You: hello
Bot: Hi! How can I help you today?

You: what is your name
Bot: I'm a simple chatbot built for the CodeAlpha internship.

You: what time is it
Bot: The current time is 05:30:00.

You: bye
Bot: Goodbye! Have a great day!
