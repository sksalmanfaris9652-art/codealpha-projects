# Hangman Game

A simple console-based Hangman game developed using Python.

## How to Play

- The computer randomly selects a word from a list of 5 words.
- Guess the word one letter at a time.
- You can make a maximum of 6 incorrect guesses.
- Guess the complete word before running out of attempts to win.

## Technologies Used

- Python
- Random module
- Loops
- Conditional statements
- Lists
- Strings

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Run the following command:

```bash
python hangman.py
