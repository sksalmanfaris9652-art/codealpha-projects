# CodeAlpha Python Programming Internship

This repository contains the Python projects completed as part of my CodeAlpha Python Programming Internship.

## Projects

### Task 1 - Hangman Game

A console-based Hangman game where the computer randomly selects a word and the player guesses it one letter at a time.

**Technologies:**
- Python
- Random module
- Lists
- Loops
- Conditional statements
- Strings

📁 `Task1_Hangman`

---

### Task 2 - Stock Portfolio Tracker

A console-based program that allows users to select multiple stocks, enter quantities, calculate individual investments, and calculate the total portfolio investment.

**Technologies:**
- Python
- Dictionaries
- Loops
- Conditional statements
- User input/output
- File handling

📁 `Task2_Stockportfolio`

---

### Task 3 - Basic Rule-Based Chatbot

A simple rule-based chatbot that responds to predefined user inputs such as greetings, questions about its purpose, the current time, jokes, and exit commands.

**Technologies:**
- Python
- Functions
- If-elif-else
- While loops
- String handling
- Date and time module

📁 `Task3_BasicChatbot`
